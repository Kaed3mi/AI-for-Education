# 一、项目概述

## 1.1 项目背景

在高校计算机专业教学中，"数据结构与算法"是核心基础课。学生常面临以下痛点：
- **解题思路不清晰**：面对编程题不知如何下手，缺乏系统化思维方法
- **调试能力薄弱**：代码出错后不知如何定位，依赖试错而非系统化诊断
- **学习反馈缺失**：教师无法为每位学生提供一对一辅导
- **代码结构设计能力不足**：缺乏"先设计后编码"的工程化思维

本项目"**航辅导**"借助大语言模型（LLM）技术，构建智能化编程辅导平台，以"**启发式教学**"为核心，引导学生自主思考，而非直接提供答案。

## 1.2 项目定位

面向高校本科生的 AI 驱动编程辅导系统，专注 C 语言数据结构与算法教学，同时支持 Python。采用**费曼学习法**和**苏格拉底式提问**，通过四阶段渐进式教学引导学生独立编写代码。

## 1.3 项目信息

| 属性 | 内容 |
|------|------|
| **项目名称** | 航辅导 —— 智能编程辅导系统 |
| **英文名** | HangFuDao - AI Programming Tutoring System |
| **开发单位** | 北京航空航天大学 |
| **核心 AI 引擎** | 小航大模型（XHang LLM） |
| **目标课程** | 数据结构与算法 |
| **支持语言** | C 语言、Python |

# 二、需求分析

## 2.1 用户角色

| 角色 | 描述 |
|------|------|
| **学生** | 计算机专业本科生，修读数据结构课程，编程水平参差不齐 |
| **教师** | 授课教师/助教，需了解学生学习情况，减轻答疑压力 |
| **管理员** | 负责部署维护、API 密钥和模型配置 |

## 2.2 功能性需求

| 编号 | 功能 | 优先级 | 描述 |
|------|------|--------|------|
| FR-01 | 知识点选择与会话管理 | 高 | 从28个知识点中选择1-3个开始学习 |
| FR-02 | 智能题目生成 | 高 | 根据知识点和难度AI自动出题，支持自适应难度和自主出题 |
| FR-03 | 四阶段启发式辅导 | 高 | 智能审题→代码框架→伪代码→代码补全 |
| FR-04 | 代码框架可视化 | 高 | 层次化分解+ISPO模型+交互式逐层深入 |
| FR-05 | 代码提交与智能诊断 | 高 | 四种错误分类+Monaco编辑器内联标记 |
| FR-06 | 在线代码编辑与执行 | 高 | Monaco Editor + JDoodle API 编译运行 |
| FR-07 | 追问与深度交互 | 中 | 各阶段多轮对话，上下文保持 |
| FR-08 | 标准答案查看 | 中 | 预生成标准答案，练习完成后可查看 |
| FR-09 | 答题记录与掌握度追踪 | 中 | MySQL持久化，知识点正确率统计 |
| FR-10 | 自动测试点生成 | 中 | AI解析题目并生成测试数据 |
| FR-11 | 教学代理(Teaching Agent) | 低 | 多Agent架构的智能教学代理 |
| FR-12 | 希冀平台集成(JWT鉴权) | 中 | cgtoken认证，学生身份自动识别 |
| FR-13 | 多模型支持 | 中 | 6+种LLM模型热切换 |
| FR-14 | 题库检索与题目变异 | 低 | LeetCode题库+AI变异生成多种题型 |

# 四、功能模块详细设计

## 4.1 核心：四阶段启发式辅导

```
第1阶段：智能审题(思路) → 第2阶段：代码框架 → 第3阶段：伪代码 → 第4阶段：代码补全(核心语句)
      │                      │                    │                    │
   ISPO分析            层次化分解+可视化       类编程语言逻辑描述       带TODO的不完整代码
   Mermaid图表         交互式逐层深入          模块一一对应            学生补全关键部分
```

### 4.1.1 智能审题 — ISPO 模型

| 维度 | 含义 | 图标 |
|------|------|------|
| I (Input) | 输入数据分析 | 📥 |
| S (Storage) | 存储结构建议（**创新点**：相比传统IPO新增） | 💾 |
| P (Process) | 处理方法分析 | ⚙️ |
| O (Output) | 输出注意事项 | 📤 |

输出包含：题目简析、题目拆解、ISPO四维分析、Mermaid可视化图表。严格禁止给出代码或确定性方案。

### 4.1.2 代码框架 — 层次化分解

- 三种控制结构标注：顺序(📋蓝)、选择(🔀红)、循环(🔄绿)
- 每个模块用ISPO描述
- 交互式分解：学生对复杂模块点击"继续分解"进入下一层
- 分解粒度标准：简单(≤5行/单一结构/≤3变量) vs 复杂(嵌套/多步/复杂数据操作)

### 4.1.3 伪代码

使用 `if-then-else-end if`、`for-do-end for` 等控制结构，赋值用 `←`，禁止任何具体语言语法。每个伪代码块与框架叶子节点一一对应。

### 4.1.4 代码补全

生成带 `// TODO: 在这里补全代码：xxx` 标记的不完整代码。标准答案经**脱敏处理**防止LLM泄露。

### 4.1.5 模块间上下文传递链

```
思路 → 框架(依赖思路) → 伪代码(依赖思路+框架) → 核心语句(依赖全部前置)
所有模块基于标准答案保持一致性
```

## 4.2 智能代码诊断（四维度）

| 阶段 | 错误类型 | 标记色 | 典型例子 |
|------|---------|--------|---------|
| 编译 | 语法错误 | 🔴红 | 括号不匹配、缺分号 |
| 运行时 | 运行时错误 | 🟠橙 | 空指针、数组越界、除零 |
| 结果 | 逻辑错误 | 🟡黄 | 循环边界错、条件写反 |
| 语义 | 语义错误 | 🟣紫 | =与==混淆、scanf缺& |

诊断输出附带JSON标记块，用于Monaco编辑器精确高亮错误行。

## 4.3 题目生成与管理

- **AI自动出题**：根据知识点+难度生成，同时后台生成标准答案
- **自主出题**：学生粘贴题目，系统自动生成标准答案
- **自适应难度**：连续答对自动升级（简单→中等→困难）
- **题库变异**：LeetCode种子题+AI变异→代码填空/Bug查找/性能分析/方案设计四种题型

## 4.4 测试点自动生成(generator_kit)

```
题目描述 → ProblemParser解析 → 结构化对象 → TestCaseGenerator → [{input, output}]
```

## 4.5 智能助教（自由对话模式）

独立于四阶段的苏格拉底式对话，自动检测粘贴题目并引导思考而非给答案。
