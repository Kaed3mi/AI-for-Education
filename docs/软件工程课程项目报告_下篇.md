## 6.5 流式响应（SSE）设计

后端使用 Python 生成器 + Flask `stream_with_context` 实现：

```python
def generate_response():
    llm = get_llm(model_name)
    for content_piece in llm._call(prompt):
        yield content_piece

return Response(stream_with_context(generate_response()), mimetype='text/event-stream')
```

前端使用 `fetch` + `ReadableStream` 实时读取：

```javascript
const reader = response.body.getReader();
while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    // 实时更新UI
}
```

# 八、AI 与大语言模型集成

## 8.1 多模型架构

| 模型类 | 名称 | 参数 | 用途 |
|--------|------|------|------|
| `XiaohangLLM` | 小航大模型 | — | 默认，北航自研 |
| `OllamaLLM` | XHang(Ollama) | — | 智能助教 |
| `LoopCoderLLM` | LoopCoder-40B | 40B | 数据结构专业 |
| `LoopCoderLLM2` | LoopCoder-400B | 400B | 增强版 |
| `NormalLLM` | IQuest-Coder-V1 | 40B MoE | 通用编程 |
| `OpenAIServerModel` | Qwen3-235B | 235B MoE | 测试/论文 |

通过 `get_llm(model_name)` 工厂函数实现热切换。所有模型继承自 LangChain `LLM` 基类，统一 `_call()` 生成器接口。

## 8.2 提示词工程

### 基础系统提示词
- 角色：智能AI助教，数据结构与算法教学
- 方法论：费曼学习法 + 苏格拉底式提问
- 核心原则：永远不直接提供完整代码，用引导性问题激发思考
- 语言适配：根据C/Python动态调整语言特性描述

### 四阶段专用提示词
每阶段包含：角色定义、输出结构要求、格式规范、禁止事项、正确/错误示例。

### 一致性约束
所有模块基于标准答案约束，后续模块自动获取前置输出作为上下文：
- 思路 → 框架约束
- 框架 → 伪代码约束（+ 叶子节点列表）
- 伪代码 → 核心语句约束

### 标准答案脱敏
代码补全模块中，标准答案移除具体实现代码，仅保留函数签名和结构描述，防止LLM直接复制。

## 8.3 Generation Token 竞态防护

防止用户快速切换题目时的异步生成冲突：
1. 每次切换题目 → Redis中 `gen_token` 递增
2. 后台生成任务定期检查token
3. token不匹配 → 立即取消当前生成

# 十一、适用人群分析

## 11.1 用户画像

### 初学者（编程小白）
- **痛点**：看到题目无从下手
- **价值**：四阶段全流程使用，代码框架建立结构化思维
- **推荐**：智能审题→框架→伪代码→代码补全

### 有一定基础的学生
- **痛点**：复杂题不知选什么算法，代码常有逻辑错误
- **价值**：ISPO帮助选择数据结构，诊断精准定位问题
- **推荐**：智能审题 + 代码诊断

### 进阶学生
- **痛点**：需要更多题目练习和标准答案对比
- **价值**：AI出题 + 多题型 + 自适应难度 + 标准答案
- **推荐**：直接做题 → 提交 → 查看答案 → 对比优化

### 教师/助教
- **痛点**：无法个性化辅导每位学生
- **价值**：系统代替一对一辅导，统计数据了解整体情况
- **推荐**：全校统计 + 掌握度追踪

# 十二、项目创新点与亮点

## 12.1 教学方法创新

|--------|------|
| **ISPO模型** | 在IPO基础上增加Storage维度，强调先选数据结构再编码 |
| **四阶段渐进辅导** | 思路→框架→伪代码→代码补全，符合认知规律 |
| **苏格拉底式AI** | 不给答案，提问引导自主思考 |
| **交互式层次化分解** | 学生主导分解深度，建立自顶向下设计思维 |
| **四维度错误诊断** | 语法/运行时/逻辑/语义精准分类，培养系统化调试能力 |

## 12.2 技术实现创新

| 创新点 | 描述 |
|--------|------|
| **模块间上下文传递链** | 前置模块输出自动传递，保证四阶段一致性 |
| **标准答案脱敏** | 防止LLM在代码补全中泄露完整代码 |

| **叶子节点一致性同步** | 框架叶子节点自动同步到伪代码和代码补全 |
